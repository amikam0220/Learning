# Binary

 "On" state when electricity is flowing, represents true. "Off" state, no electricity flowing, represents false.

## Advantage:

Simple and there has been ==Boolean algebra== focusing on the computing about true and false.

# Early Computer-Ternary even Quinary

## Flow:

# Boolean Algebra

The value of variables are true and false and the operations are logical(basically including ==and, or and not==)

The NOT Boolean logic gate can be easily built by transistors through ==moving the output line before the upper electrode== and ==move the origin output to the ground==.
![[Constructure of NOT gate 1.png]]![[Constructure of NOT gate 2.png]]
The AND gate can be built by connecting two transistors and only when two transistors all does then the output will have current.
![[Constructure of AND gate.png]]
The OR gate can be built by constructing a parallel circuit of two transistors and when one of the two transistors does or all does then the output will have current.
![[Constructure of OR gate.png]]Another Boolean operation is XOR.  
![[Constructure of XOR gate.png]]

More advanced components can be constructed by these basic primitive.
