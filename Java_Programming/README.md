# 课程简介 -- Java程序设计和实验（全英）

这门课的授课老师是Y. X. Sun，老师挺不错的，并不会特别为难人，有些迟到早退之类的也可以和她讲明情况，期末给分也比较高。

关于课程，这门课的难度不大，但是事情并不算很少，她要求你写一个课程报告和实验报告（都是期末再交，但是每周都要做）。课程报告是她每周讲的内容的quiz，你需要做一遍然后把最后正误情况写到报告上，并且写你学到了啥，任务量不小；实验报告就写一些代码实现、运行结果和bug修复（她说每个实验你肯定都会遇到bug所以都要写）等等。实验课也会偶尔查看你的实验进度~~以及有没有偷偷使用vibe coding或者开了一把~~。对课程本身，虽然说有点用但是不多，只能说vibe coding已经把这门课最后一块遮羞布给扯下来了，拥抱新质生产力吧同志们。

关于考勤，理论课不会考勤，实验课会在每节课最后一节课的时候开始点名，而且选这门课的学生也不多，所以想找个人帮忙点名然后自己美美跑路的事情一般不太现实~~所以只能忍痛只逃最后一节课~~。

关于给分，这门课没有闭卷的期末考试，只需要提交上文中的两个实验报告，以及做一个大作业，会让你自选课题，主要是在前人的代码上修修改改实现一些功能。这两门课有意愿努努力的话两个90+是没啥问题的，没意愿也没事，挂科几率更是小于满分几率，所以这门课总体无毒无害，可以放心食用。
