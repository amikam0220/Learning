## Phrase-Structure Grammars

- ==Vocabulary== set $V$ is a ==finite, nonempty set of elements== called ==symbols==.
- ==Word== over $V$ is a string of finite length of elements in $V$.
- ==Empty string or null string== contains no symbols, denoted by $\lambda$
- The set of ==all words over $V$== is denoted by $V^{*}$. A ==language== over $V$ is a subset of $V^{*}$.
- The elements of $V$ that can ==not be replaced== are called ==terminals==; others are called ==nonterminal==.
- The rules that specify when we can replace a string with another string in $V^{*}$ are called ==productions== of the grammar, denoted by $z_{0}\to z_{1}$ that $z_{0}$ can be replaced by $z_{1}$ within a string.

A ==phrase-structure grammar== $G=(V,T,S,P)$ consist a vocabulary $V$, a terminal subset $T$ of $V$, a start symbol $S$ from $V$, a finite set of productions $P$. Nonterminal symbol set $N=V-T$. Every production in $P$ must contains at least one nonterminal on its left side.

Example:
Let $G=(V,T,S,P)$ where $V=\{ a,b,A,B,S \}$, $T=\{ a,b \}$, $S$ is the start symbol and $P=\{ S\to Aba,A\to BB,B\to ab,AB\to b \}$.

Step 1: Replace $S$ by $Aba$;
Step 2: Replace $A$ by $BB$;
Step 3: Replace $B$ by $ab$.

Then all symbols are terminals thus the result is $ababba$.
To summarize, continue to replace the nonterminal to terminals.

## Derivations

Let $G=(V,T,S,P)$ be a phrase-structure grammar. $w_{0}=lz_{0}r$, $w_{1}=lz_{1}r$ are strings over $V$. If $z_{0}\to z_{1}$ is a production of $G$, we say $w_{1}$ is ==directly derivable== from $w_{0}$, denoted by $w_{0}\implies w_{1}$.

If $w_{0}\implies w_{1},w_{1}\implies w_{2},\cdots,w_{n-1}\implies w_{n}$, then $w_{n}$ is ==derivable== from $w_{0}$ and write $w_{0}\implies w_{n}$. The sequence of steps used to obtain $w_{n}$ from $w_{0}$ is called a ==derivation==.

Example: $Aaba$ is directly derivable from $ABa$. $ababba$ is derivable from $Aba$.

## Language Generation

Let $G=(V,T,S,P)$ be a phrase-structure grammar. The ==language generated== by $G$, denoted by $L(G)$ is the set of all ==strings or terminals== that ==derivable from the starting state $S$==.

For example, $G=(\{ S,A,a,b \},\{ a,b \},S,\{ S\to aA,S\to b,A\to aa \})$, then $L(G)=\{ b,aaa \}$ (all possible results)

## Derivation Trees

We can represent a derivation in the language generated by ==context-free grammars== by an ordered rooted tree, called a ==derivation or parse tree==.
- root is start symbol
- internal vertices represent nonterminal symbols
- leaves represent terminal symbols
- for $A\to w$, where $w$ is a word, $A$ has children vertices represent each symbol in $w$ in order from left to right.

![[derivation trees.png]]

## Backus-Naur Form

BNF is sometimes used to ==specify type 2 grammar==. It is often used to specify the syntactic rules of computer languages.

- Use symbol $::=$ instead of $\to$
- All nonterminal symbols are enclosed by $\langle\rangle$
- Right-hand side of productions are separated by bars

For example, the production $A\to Aa,A\to a,A\to AB$ are written as 
$$
\langle A \rangle::=\langle A \rangle a |a|\langle A \rangle\langle B \rangle
$$

## BNF and ALGOL 60

In programming language ALGOL 60, identifiers consist a string of alphanumeric characters and must begin with a letter.

Allowable BNF description:
$$
\begin{align}
 & \left< identifier \right> ::=\left< letter \right> |\left< identifier \right> \left< letter \right> |\left< identifier \right> \left< digit \right>  \\
 & \left< letter \right> ::=a|b|\cdots|y|z \\
 & \left< digit \right> ::=0|1|\cdots|9
\end{align}
$$

## Unit-delay Machine

Unit-delay machine produces as output the input string delayed by a specified amount of time. i.e., ==padded with an initial string of $0$s==.

A delay machine can be constructed that has $0$ or $1$ as possible inputs. It start at state $s_{0}$, transition from $s_{0}$ produces an output of $0$. $s_{1}$ receive input $0$ and output $1$ to state $s_{2}$. $s_{2}$ receive $1$ and output $0$ to $s_{1}$. Thus input $101$ output $010$, delay a specified amount of time.

## Addition Machine

Add two positive integers using their ==binary expansions== $(x_{n}\cdots x_{1}x_{0})_{2}$ and $(y_{n}\cdots y_{1}y_{0})_{2}$. Every addition receive input $x_{i},y_{i}$ and a carry bit $c_{i-1}$ and output a sum bit $z_{i}$ and a carry bit $c_{i}$. Repeat until the most significant digit and the last carry $c_{n}$ is the MSD of result $z_{n+1}$.

## Set of Strings

FSMs without output but with some states designated as ==accepting states== are designed for ==recognizing languages==.

The ==concatenation== of $A$ and $B$ where $A,B$ are subset of $V^{*}$, denoted by $AB$ is the ==set of all strings of the form $ab$== where $a\in A,b\in B$.
For example, $A=\{ 0,11 \},B=\{ 1,10,110 \}$, then $AB=\{ 01,010,0110,111,1110,11110 \}$, $BA=\{ 10,111,100,1011,1100,11011 \}$.

If $A\subseteq V^{*}$, the ==Kleene closure== of $A$ denoted by $A^{*}$ is the set consisting of arbitrarily long strings of elements of $A$, that is, $A^{*}=\cup_{k=0}^{\infty}A^{k}$. ($A^{k}$ is the string with length $k$).

## Finite-State Automata(FSA)

It is finite-state machine without output but with accepting states.
A finite-state automaton $M=(S,I,f,s_{0},F)$ consists of a ==finite set $S$ of states==, a ==finite input alphabet $I$==, a ==transition function== $f$ that assigns a next state to every pair of state and input, an ==initial or start state $s_{0}$== and a ==subset $F$ of $S$ consisting of final(or accepting) states==.

It also can be represented by ==state table or state diagrams==, in which final states are indicated with ==a double circle==.

## NDFSA

Nondeterministic finite-state automaton $M=(S,I,f,s_{0},F)$ consists of a finite set $S$ of states, a finite input alphabet $I$, a transition function $f$ that assigns ==a set of states== to every pair of state and input, an initial or start state $s_{0}$, and a subset $F$ of $S$ consisting of final (or accepting) state.
The distinction between before DFSA and NDFSA is that ==the transition function==. The result of transition function of NDFSA is ==not unique state but a set of states==.

A string is recognized by NDFS if and only if there exist at least transition path from $s_{0}$ to a accepting state in $F$.

It also can be represented by state diagram and state table.

## Finding a DFSA Equivalent to a NDFSA

For every NDFSA ==there is an equivalent DFSA==. 
We construct the DFSA $M_{1}$ equivalent to NDFSA $M_{0}$ so that
- ==Each state== in $M_{1}$ is made up of ==a set of states in $M_{0}$==. (For example, the set states in $M_{0}$ is $\{ s_{0},s_{1} \}$, then one state in $M_{1}$ is $\{ s_{0},s_{1} \}$)
- Start symbol of $M_{1}$ is $\{ s_{0} \}$.
- Input set of $M_{1}$ is the same as input set of $M_{0}$.
- For a state $\{ s_{i_{1}},\cdots,s_{i_{k}} \}$ in $M_{1}$, the input symbol ==takes this state to the union of the sets of next states for the elements of this set==. That is the union of the sets $f(s_{i_{1}},x),\cdots,f(s_{i_{k}},x)$.
- The final states of $M_{1}$ are the sets that ==contain final state== of $M_{0}$.

## Regular Expressions

==Regular expressions== over a set $I$ is defined ==recursively== by:
- the symbol $\emptyset;\lambda;x$ is a regular expression where $x \in I$.
- The symbol $(AB),(A\cup B)$ and $A^{*}$ are regular expression whenever $A$ and $B$ are regular expressions.

Sets represented by regular expressions are called ==regular sets==.

Example: explain the strings in the regular sets specified by the regular expressions $10^{*},(10)^{*},0\cup 01,0(0\cup 1)^{*},(0^{*}1)^{*}$

## Finite-State Automata, Regular Sets and Regular Grammars

Kleene's Theorem:
A set is regular if and only if it is recognized by a FSA.

A set is generated by a regular grammar if and only if it is a regular set.

## A Set Not Recognized by a FSA

The set $L=\{ 0^{n} 1^{n} |n=0,1,\cdots\}$ is not regular. It can be proved by contradiction. To show there is no NDFSA recognizing it.

## Introduction

Informally, a Turing machine consists of a control unit together with a tape that infinite in both directions, which is divided into cells.

Turing machines are the ==most general models of computation==.
![[informal introduction of Turing machine.png]]

## Definition of Turing Machine (TM)

A Turing machine $T=(S,I,f,s_{0})$ consists of ==a finite set $S$ of states==, an ==alphabet $I$ containing the blank symbol $B$==, a ==partial function== $f$ from $S\times I$ to $S\times I\times \{ R,L \}\text{(direction)}$ and a ==starting state== $s_{0}$.

$f$ is partial function. i.e., for some (state, symbol) pairs it may be undefined. For defined, there is a unique (state, symbol, direction) triple associated to this pair.

The corresponding five-tuples $(s,x,s ^{\prime},x^{\prime},d)$ are called ==transition rules== of the machine.
At each step, control unit ==reads current tape symbol $x$==, then for current state $s$ and the partial function $f(s,x)=(s ^{\prime},x^{\prime},d)$, the control unit:
- enter the state $s ^{\prime}$
- write the symbol $x^{\prime}$ in current cell and erase $x$
- Move right or left one cell depends on $d$.

When the partial function is undefined, the machine will ==halt==. The initial state is positioned over the ==leftmost nonblank symbol== on the tape. This is the ==initial position== of the machine.

For ==nondeterministic Turing machine(NDTM)==, the restriction that no two transition rules begin with the same pair $(s,x)$ is elimianted.

## Using TM to Recognize Sets

Let $V$ be a subset of alphabet $I$. $T=(S,I,f,s_{0})$ ==recognizes== a string $x$ in $V^{*}$ if and only if when $x$ is written on the tape $T$ starting in the initial position and halts in a final state.

$T$ is said to recognize a subset $A$ of $V^{*}$ if $x$ is recognized by $T$ if and only if $x \in A$. (We can use symbols not in $V$)

For the set $\{ 0^{n}1^{n}|n\geq 1 \}$ that cannot be recognized by DFA, TM can recognize this set. $V=\{ 0,1 \},I=\{ 0,1,M \}$ where $M$ is a marker. TM successively replaces a $0$ at leftmost position of string with $M$ and a $1$ at the rightmost position of the string with $M$. Terminate if and only if the string consists of same number of 0 and 1.

## Computing Functions with TMs

Suppose $T$ when given string $x$ as input, halts with the string $y$ on its tape. We can define $T(x)=y$.

We use ==unary representation of integers== to consider a TM as a computer from the set $k$-tuples of nonnegative integers to the set of nonnegative integers. And we use $*$ to separate different integers in $k$-tuple($n$ is represented by $n+1$ 1s, for example, $5$ is $111111$, $(2,0,2,5)$ is $111*1*111*111111$)

To compute $f(n_{1},n_{2})=n_{1}+n_{2}$, 
- transfer the pair by unary representation
- Start at the left most 1 of the input string and proceeds to erase this 1.
- If the next is $*$, $n_{1}=0$ and then replace the asterisk with blank and halts
- Otherwise, erase next 1 and pass over the remaining $1$s until encountering $*$ and then replace it by $1$.

## The Church-Turing Thesis

Any problem that can be solved with an ==effective algorithm==(informal and imprecise concept), there is a $TM$ that can solve this problem(formal and precise concept).

## Decidability and Complexity

- ==Decision problem== asks whether statements from a particular statements are true. (Like halting problem)
- If there is an ==effective algorithm== decides the decision problem, the problem is ==solvable or decidable==. (halting problem is unsolvable)
- A function that can be computed by TM is called ==computable==. (Busy beaver function is incomputable)

## The Classes P and NP

If a problem can be solved by DTM in polynomial time in terms of the size of input, it is in ==the class of polynomial-time problems==, or ==Class P==.

If a problem can be solved by NDTM in polynomial time in terms of the size of input, it is in ==the class of nondeterministic polynomial-time problems==, or ==Class NP==.

Problems in $P$ are called ==tractable== while not in $P$ are called ==intractable==.

Since DTM can also be considered to be a NDTM, $P \subseteq NP$. (problem: whether $P=NP$)

NP-complete problems: 
- It is in class NP 
- If the existence of a polynomial-time algorithm for solving it, there exist a polynomial-time algorithm for ==every problem in NP==.
