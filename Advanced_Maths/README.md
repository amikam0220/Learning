# 课程简介--高等数学I、II（信息类）（全英）

这门课并非传统高数，是国际学院特色高等数学，**主要体现在出卷和给分都是国院自己的老师解决**，因此**两个授课老师的给分和出卷会很不一样**，详见授课老师部分，按下不表。难度方面也因此比正常理工科高数要简单一些，所以如果想要考研的话可能要补的微积分部分有点多。

这门课分为上下两个学期教完一本Thomas Calculus，实际教学时会有部分跳过的章节，请仔细**跟着老师节奏走**，~~实在不行跟着你听过课的舍友走~~，不然只听网课的话，对这门课的作用不是很大，因为我们是神奇国院。同时也**不很建议硬啃课本**，这本书实在有点食之无味弃之可惜了。

高数老师24级后内招是L. Q. Wu，外招是L. H. Xia。如果你是外招生的话请自己偷摸高兴，因为伟大的Mr. Xia不仅会布置课下作业还会有**考前模拟卷**，跟着做的话95+不是问题，本仓库里的Notes也应该完全够用。
如果你是内招生的话，请完成以下规则怪谈：

- **不要在他课上迟到或者说话**，这位老师很注重大学课堂纪律，实在迟到的话等下一节课，再不济就不去了也不要迟到，否则你将喜提姓名大字报，严重会有*没有教学的义务*的情况出现；
- **不要翘掉最后一节课的考勤**，一般来说他是根据这次给平时分的，虽然他说期末权重远大于平时分，但是如果你复习成色不怎么样他还是会一定程度上通过平时分帮你一下的；
- 看到试卷发下来后**一张试卷只有几道几十分值的大题**不要慌张，因为他出题就是这样的；
- 不要相信L. Q. Wu会捞人，还是要学的差不多的，起码要把**他给过的课后题都做一遍**，~~否则就会出现我舍友的57分惨案~~，刷高分就要有空多做了；
- 不要相信L. Q. Wu说的不捞人，~~差不多的时候他还是会稍微拉你一把的~~，不要太害怕。

其他方面的话，**Mr. Wu授课**一般是会用**中文**的，所以讲课节奏会快一些，消化不了的话也是有可能的。此外，他的课确实不点名，所以可以算水课(?)。

本人第一学期是Mr. Xia教学，99/100；第二学期改为Mr. Wu教学，86/100。只能说对内招生的这门课程，各位量力而行吧。
