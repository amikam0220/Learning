# Course Description

- Learn modular design of software and documenting the design using symbolic representations, covering software life-cycle models and different phases of the software development process
- ==Object-orient== techniques are key to the course.
- Having project works: individual work, teams of two to three students work on developing complex software systems over a course of one semester.

# Grading

- Exercise Homework and Class Participation: 15%
- Project: 25%
	Project reports(2 projects, 4 version of reports):25 + 10
- Exam: 60% (Closed-book, from projects, Lectures & exercises)
	Two weeks ahead to review

# Syllabus at a Glance

Ch1-Ch5 only, and some topic
