# Tips

# Requirements

课本，精简一下不要照抄
预期报告，跟着pdf做
普通物理学实验（暨南大学慕课）

预期报告需要包括：
	实验目的
	实验原理
	实验步骤
	数据表格
采用暨大实验报告纸 A3
老师会检查预期报告

签到、准备实验、聆听实验介绍、开始实验、记录数据、==实验后请老师签字==、整理实验设备、签离
以老师为准
在预习报告基础上完成==数据分析与思考题==，下次实验开始时提交实验报告

# Scores

- 预习报告10分
- 实验操作50分
- 实验报告40分
重视==数据处理、思考题、实验总结==

# Measurement

- 直接测量：用相应工具直接测量数据
- 间接测量：用其余直接测量物理量计算
- 不确定度和误差：(Uncertainty and error)
	数字仪表、电阻箱等不用估读，注意有效数位，运算结果精度就低不就高

# Analysis

- 列表法：表头、原始数据等
- 作图法：允许电脑作图，手动拟合时注意
- 逐差法：分一半相隔减
