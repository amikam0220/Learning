# 课程简介 -- 英语读写 I、II

这门课的老师每一届都不固定，我们那届读写I是Adam上课，读写II是Cecilia上课。Adam的话讲课个人风格挺明显的~~而且还是个百万粉大网红会讲脱口秀~~，但是考试相关的东西并不会提醒太多，课程学习也没有盯太紧，偶尔有点作业做一做就行。Cecilia是一个挺儒雅随和的老师，但是她每节课都会有相应的任务，相对来说作业也要多一点，对考试帮助也会大一些。

关于课程，读写I是吓人的4学分（貌似后续各大专业课都没有能到4学分的），读写II是正常的2学分。以及简单和大一新生介绍一下绩点的算法是

$$
\frac{\sum(课程绩点\times课程学分)}{\sum课程总学分}  
$$

所以你就大概可以理解这个英语读写I能占绩点多大比重。课程本身难度并不是很大，和高中英语课体感差不多，除了老师只会讲洋文以及提问的频率变高了。这门课主要还是让大伙适应一下全英教学~~（虽然讲完也未必能适应·）~~，不过如果对绩点有要求的话还是要多看看课本。

关于考勤，这两个老师貌似都会上课很频繁地提问，所以如果你没去就要做好既没有出勤分也没有提问平时分的准备。

关于给分，期末考试内容比较多，包括
- 课本知识（填空、知识点名词）
- 阅读理解（3篇左右，形式和高考阅读差不多）
- 作文（250词）
- ...

所以一小时五十分钟的时间还需要大家合理安排，不要等做不完了空悲切。老师一般会在最后一节课之前大概讲一下考纲，所以也不用特别害怕考试内容。这门课给分还是挺平均的，基本都在80到90之间，偶尔英语比较好的可以达到90+。顺便本仓库由于是大一下学期才开始把笔记上云，上学期没有使用电子化笔记，所以没有相关的笔记（不过我印象里Adam也没给我们做多少笔记就是了...）
