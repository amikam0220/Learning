# 先序中序后序遍历

## 先序遍历

遍历过程为：
- 访问==根节点==
- 先序遍历其==左子树==
- 先序遍历其===右子树===

```
void PreOrderTraversal(BinTree bt){

    if (bt){

        printf("%d", bt->data);

        PreOrderTraversal(bt->left);

        PreOrderTraversal(bt->right);

    }

}
```

![[PreorderTraversal.png]]
## 中序遍历

遍历过程为：
- 中序遍历其左子树
- 访问根节点
- 中序遍历其右子树

```
void InOrderTraversal(BinTree bt)

{

    if (bt)

    {

        InOrderTraversal(bt->left);

        printf("%d", bt->data);

        InOrderTraversal(bt->right);

    }

}
```

![[InOrderTraversal.png]]
## 后序遍历

遍历过程为：
- 后序遍历其左子树
- 后序遍历其右子树
- 访问根结点

```
void PostOrderTraversal(BinTree bt)

{

    if (bt)

    {

        InOrderTraversal(bt->left);

        InOrderTraversal(bt->right);

        printf("%d", bt->data);

    }

}
```

![[PostOrderTraversal.png]]

先序、中序、后序遍历过程中经过结点的==路线一样==，只是==访问各结点的时机不同==。
每个结点都会经过三次，第一次经过即输出即为先序，第二次为中序，第三次为后序

# 二叉树的非递归遍历

## 前序遍历非递归遍历算法

基本实现思路：==使用堆栈==
- 遇到一个结点，先将其弹出并访问
- 先将其右结点压栈
- 再将其左结点压栈
或者使用类似中序遍历递归算法，
- 遇到一个结点，先访问该结点，然后再将其压栈并遍历其左子树
- 左子树遍历结束后按其右指针去前序遍历该结点的右子树
对应的代码实现只需要挪动`printf`语句的位置
## 中序遍历非递归遍历算法

基本实现思路：==使用堆栈==
- 遇到一个结点，就把它==压栈==，并遍历其==左子树==；
- ==左子树遍历结束后==，从栈顶弹出该结点并==访问==；
- 按其右指针去中序遍历该结点的==右子树==；

## 后序遍历非递归遍历算法

基本实现思路：==使用堆栈==
注意，仅挪动前序或中序算法中的`printf`函数不能实现，因为根结点必须最后访问，但是返回根结点时无法直接知道是否已经处理过左、右子树。
具体解决方法可以使用两个栈，先将结点按先左后右的顺序压入第一个栈内，再将其弹出并压入另一个栈内，最后输出第二个栈实现后序遍历
或使用在结构内使用标记来标记根结点，记录是否处理过左、右子树

```
typedef int Elementype;

typedef Tnode *Position;

typedef Position BinTree;

typedef Snode *Stack;

typedef struct Tnode

{

    Elementype data;

    BinTree left;

    BinTree right;

} Tnode;

typedef struct Snode{

    Tnode* node;

    struct Snode *next;

} Snode;

void PushSnode(Stack* tops, BinTree bt){

    if(!bt){

        return;

    }

    Stack newnode = (Stack)malloc(sizeof(Snode));

    newnode->node = bt;

    newnode->next = *tops;

    *tops = newnode;

    return;

}

BinTree PopSnode(Stack* tops){

    if (!*tops){

        return;

    }

    Stack tmp = *tops;

    *tops = (*tops)->next;

    BinTree ret = tmp->node;

    free(tmp);

    return ret;

}

void PreOrderTraversal(BinTree bt){

    if (!bt)

        return;

    Stack stk = NULL;

    PushSnode(&stk, bt);

    while (stk){

        BinTree tmp = PopSnode(&stk);

        printf("%d", tmp->data);

        if (tmp->right){

            PushSnode(&stk, tmp->right);

        }

        if (tmp->left){

            PushSnode(&stk, tmp->left);

        }

    }

}

void InOrderTraversal(BinTree bt){

    if (!bt)

        return;

    Stack stk = NULL;

    BinTree itr = bt;

    while(stk || itr){

        while (itr){

            PushSnode(&stk, itr);

            itr = itr->left;

        }//push the node to stack and traverse the left subtree

        BinTree tmp = PopSnode(&stk);//use a variable to receive the Popped node to traverse the right subtree

        printf("%d", tmp->data);//visit the node

        itr = tmp->right;//cope with the right subtree of the node

    }

}

void PostOrderTraversal(BinTree bt){

    if (!bt)

        return;

    Stack stk1 = NULL;

    Stack stk2 = NULL;

    PushSnode(&stk1, bt);

    while (stk1){

        BinTree tmp = PopSnode(&stk1);

        PushSnode(&stk2, tmp);

        if (tmp->left)

            PushSnode(&stk1, tmp->left);

        if (tmp->right)

            PushSnode(&stk1, tmp->right);

    }

    while (stk2){

        BinTree tmp = PopSnode(&stk2);

        printf("%d", tmp->data);

    }

}
```

# 层序遍历

二叉树遍历的核心问题：==二维结构的线性化==。
即从结点访问其左、右儿子结点，访问左儿子后，父结点、右儿子结点怎么办
所以需要一个存储结构保存暂时不访问的结点，此存储结构为堆栈或者队列
在前序、中序、后序遍历中，使用的是==堆栈==来保存==父结点==
在层序遍历中，使用==队列==来保存==右儿子结点==

基本实现思路：
- 将根结点入队后执行循环，先使结点出队
- 再访问该结点
- 最后使其左右儿子入队

```
typedef int Elementype;

typedef Tnode *Position;

typedef Position BinTree;

typedef Snode *Stack;

typedef Qnode *Queue;

typedef struct Tnode

{

    Elementype data;

    BinTree left;

    BinTree right;

} Tnode;

typedef struct Snode{

    Tnode* node;

    struct Snode *next;

} Snode;

typedef struct Qnode{

    Snode *front;

    Snode *rear;

} Qnode;

void AddQ(Queue q, BinTree bt){

    Snode* newnode = (Snode*)malloc(sizeof(Snode));

    newnode->node = bt;

    newnode->next = NULL;

    if (q->front != NULL){

        q->rear->next = newnode;

        q->rear = newnode;

    }else{

        q->rear = q->front = newnode;

    }

}

BinTree DeleteQ(Queue q){

    if (q->front == NULL)

        return NULL;

    Snode* tmp = q->front;

    q->front = q->front->next;

    if (q->front == NULL){

        q->rear = NULL;

    }

    BinTree ret = tmp->node;

    free(tmp);

    return ret;

}

void LevelOrderTraversal(BinTree bt){

    if (!bt)

        return;

    Queue q = (Queue)malloc(sizeof(Qnode));

    q->rear = NULL;

    q->front = NULL;

    AddQ(q, bt);

    while(q->front){

        BinTree tmp = DeleteQ(q);

        printf("%d", tmp->data);

        if (tmp->left)

            AddQ(q, tmp->left);

        if (tmp->right)

            AddQ(q, tmp->right);

    }

    free(q);

}
```

# 遍历应用例子

## 输出二叉树中的叶子结点

直接在二叉树的前序遍历算法中增加检测结点的==左右子树是否都为空==

## 求二叉树的高度

分别遍历求出左右子树的深度，再求左右子树较大的深度，最后返回树的深度

## 二元运算表达式树及其遍历

三种遍历可以得到三种不同的访问结果，先序、中序、后序遍历可以分别得到前缀、中缀、后缀表达式

![[二元运算表达式树.png]]
- 先序遍历得到表达式 $++a*bc*+*defg$
- 中序遍历得到表达式$a+b*c+d*e+f*g$
- 后序遍历得到表达式 $abc*+de*f+g*+$

注意中缀表达式会受到==运算优先级==的影响，解决方法是输出左子树前输出左括号，输出结束后输出右括号

## 由两种遍历序列确定二叉树

==必须有中序遍历==才能唯一确定一棵二叉树

### 先序和中序遍历序列确定唯一二叉树

- 根据==先序遍历==第一个结点确定==根结点==
- 根据根结点在==中序遍历序列==中分割出左右两个子序列
- 对==左右子树分别递归使用==相同的方法继续分解

类似方法也可以用中序和后序遍历序列确定唯一二叉树
