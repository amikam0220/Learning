# 队列及顺序存储实现

## 什么是队列

==队列==(Queue)是具有一定操作约束的线性表
只能在==一端==插入，而在==另一端==删除
- 数据插入：入队列(AddQ)
- 数据删除：出队列(DeleteQ)
- 先进先出：FIFO

## 队列的抽象数据类型描述

- 类型名称：队列 (Queue)
- 数据对象集：一个有0个或多个元素的有穷线性表
- 操作集：长度为`Maxsize`的队列$Q\in \mathrm{Queue}$，队列元素$\mathrm{item}\in \mathrm{Elementype}$
	- `Queue CreateQueue(int Maxsize)`：生成相应最大长度的空队列
	- `int IsFull(Queue Q, int Maxsize)`：判断队列是否已满
	- `void AddQ(Queue Q, Elementype item)`：将元素插入到队列中
	- `int IsEmpty(Queue Q)`：判断队列是否为空
	- `Elementype DeleteQ(Queue Q)`：将队头数据元素从队列中删除并返回

## 队列的顺序存储实现

由一个==一维数组==和一个记录队列头元素位置的变量==front==以及一个记录队列尾元素位置的变量==rear==组成

## 循环队列

当队列的rear大于数组上限而front又已经向前移动使数组产生空位时，可以采用==循环队列==来提高利用率。
注意，一个大小为n的数组，rear与front的相对位置关系有n-1种，而对应的实际排列情况有n种，导致==无法直接使用rear与front相对位置关系来判断队列为空或满==。
解决方法：
- 使用额外标记：Size或者tag域记录最后一次操作
- ==仅使用n-1数组空间==
```
typedef struct Qnode{

    Elementype data[Maxsize];

    int front;

    int rear;

} Qnode;

typedef Qnode *Queue;

Queue CreateQueue(){

    Queue que = (Queue)malloc(sizeof(Qnode));

    if(!que){

        printf("Fail to allocate the memory.\n");

        return NULL;

    }

    que->rear = 0;

    que->front = 0;

    return que;

}

int IsFull(Queue que){

    return ((que->rear + 1) % Maxsize == que->front);

}

void AddQ(Queue que, Elementype item){

    if (IsFull(que)){

        printf("The queue is full.\n");

        return;

    }

    que->rear = (que->rear + 1) % Maxsize;

    que->data[(que->rear) % Maxsize] = item;

    return;

}

int IsEmpty(Queue que){

    return (que->front == que->rear);

}

Elementype DeleteQ(Queue que){

    if (IsEmpty(que)){

        printf("The que is empty.\n");

        return -1;

    }

    que->front = (que->front + 1) % Maxsize;

    return que->data[que->front];

}
```

# 队列的链式存储实现

队列的链式存储结构也可以用==单向链表==实现，插入和删除操作分别在链表的两头进行。
其中队列指针front指向链表的头，rear指针指向链表的尾。

```
#define ERROR -1

typedef int Elementype;

typedef struct Node{

    Elementype data;

    struct Node *next;

}node;

typedef struct Qnode{

    node *front;

    node *rear;

} Qnode;

typedef struct Qnode* Queue;

Queue CreateQueue(){

    Queue que = (Queue)malloc(sizeof(Qnode));

    que->rear = NULL, que->front = NULL;

    return que;

}

void AddQ(Queue que,Elementype item){

    node *newnode = (node *)malloc(sizeof(node));

    if (newnode == NULL){

        printf("Fail to allocate the memory.\n");

        return;

    }

    newnode->data = item;

    newnode->next = NULL;

    if (que->front == NULL){

        que->front = que->rear = newnode;

    }else{

        que->rear->next = newnode;

        que->rear = newnode;

    }

    return;

}

Elementype DeleteQ(Queue que){

    if (que->front == NULL){

        printf("The queue is empty.\n");

        return ERROR;

    }

    node *tmp = que->front;

    if (que->front != que->rear){

        que->front = que->front->next;

    }else{

        que->front = que->rear = NULL;

    }

    Elementype tmpdata = tmp->data;

    free(tmp);

    return tmpdata;

}

void PrintQueue(Queue que){

    node* itr = que->front;

    while(itr != NULL){

        printf("%d\n", itr->data);

        itr = itr->next;

    }

    return;

}
```
