# 什么是平衡二叉树

- ==平衡因子==(Balance Factor, BF)：$BF(T)=h_{L}-h_{R}$，两个参数分别为该树左、右子树的高度
- ==平衡二叉树==(Balanced Binary Tree, AVL树)：
	平衡二叉树是==搜索树==的一种
	空树，或者==任意结点==左、右子树高度差的绝对值不超过1，即为$\left| BF(T) \right|\leq 1$
![[AVL树例子.png]]
设高度为$h$的平衡二叉树最少结点数为$n_{h}$，则其满足$n_{h}=n_{h-1}+n_{h-2}+1$。
其形式与斐波那契数列相似，且有$n_{h}=F_{h+2}-1(h\geq{0})$。
由于斐波那契数列与参数为==指数关系==，则$n_{h}$与$h$为指数关系，故 $h=O(\log n)$。
给定结点数为n的AVL树，最大高度为 $O(\log n)$。

# 平衡二叉树的调整

 对于平衡二叉树插入结点后，可能存在不平衡的现象，这时需要进行调整，关键是处理==被破坏结点==和==破坏结点==的关系，根据二者的位置关系可以分为四种情况。
被破坏结点是平衡因子绝对值首次超过1的结点，破坏结点是直接导致平衡被打破的结点。

## RR旋转（左单旋）

若破坏结点在被破坏结点的==右子树的右边==，则需要进行RR旋转，即右单旋，主要是将被破坏结点的右子树上移，并将被破坏结点作为左儿子结点，将其原来右子树的左子树挂到被破坏节点的右侧。

![[RR旋转.png]]

## LL旋转（右单旋）

若破坏结点在被破坏结点的==左子树的左边==，则需要进行LL旋转，即左单旋，主要是将被破坏节点的左子树上移，并将被破坏节点作为其右儿子结点，将其原来左子树的右子树挂到被破坏结点的左侧。
![[LL旋转.png]]
## LR旋转

若破坏节点在被破坏节点的==左子树的右边==，则需要进行LR旋转，主要是将破坏节点上移，将其祖先节点作为其左子树，祖先节点的祖先节点作为其右子树，将其原左右子树分别挂到现左子树的右侧和右子树的左侧。

![[LR旋转.png]]
即先对B进行RR旋转，再对C进行LL旋转
# RL旋转

若破坏节点在被破坏节点的==右子树的左边==，则需要进行RL旋转，主要是将破坏节点上移，将其祖先节点作为其右子树，祖先节点的祖先节点作为其左子树，将其原左右子树分别挂到现左子树的右侧和右子树的左侧。
![[RL旋转.png]]

即先对B进行LL旋转，再对C进行RR旋转

具体代码实现：
```
typedef int Elementype;

typedef struct AVLnode{

    Elementype Data;

    AVLnode *left;

    AVLnode *right;

    int height;

} AVLnode;

typedef AVLnode *AVLtree;

  

int balancefactor(AVLnode* node){

    return (node == NULL) ? (0) : (node->left->height - node->right->height);

}

  

void updateheight(AVLnode *node){

    if (!node)

        return;

    node->height = (node->left->height > node->right->height) ? (node->left + 1) : (node->right + 1);

    return;

}

  

AVLnode* rightrotation(AVLnode* node){

    AVLnode *retnode = node->left;

    AVLnode *tmpnode = retnode->right;

    retnode->right = node;

    node->left = tmpnode;

    updateheight(node);

    updateheight(retnode);

    return retnode;

}

  

AVLnode* leftrotation(AVLnode* node){

    AVLnode *retnode = node->right;

    AVLnode *tmpnode = retnode->left;

    retnode->left = node;

    node->right = tmpnode;

    updateheight(node);

    updateheight(retnode);

    return retnode;

}

  

AVLnode* LRrotation(AVLnode* node){

    node->left = leftrotation(node->left);

    return rightrotation(node);

}
```
