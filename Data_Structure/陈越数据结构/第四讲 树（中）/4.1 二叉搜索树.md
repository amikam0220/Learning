# 二叉搜索树及查找

## 什么是二叉搜索树

二叉搜索树(BST, Binary Search Tree)，也称二叉排列树或二叉查找树
可以为空，如果不为空，满足以下性质：
- 非空左子树的所有键值小于其根结点的键值
- 非空右子树的所有键值大于其根结点的键值
- 左、右子树都是二叉搜索树

## 二叉搜索树操作的特别函数

- `Position Find(Elementype X, BinTree BST)`：从二叉搜索树中查找某元素并返回其所在结点的地址
- `Position FindMin(BinTree BST)`：从二叉搜索树中查找并返回最小值的地址
- `Position FindMax(BinTree BST)`：从二叉搜索树中查找并返回最大值的地址
- `BinTree Insert(Elementype X, BinTree BST)`：插入
- `BinTree Delete(Elementype X, BinTree BST)`：删除

### 二叉搜索树的查找操作Find

可以使用递归，但递归都为尾递归（程序返回时使用递归），效率不高
可以用循环进行实现

```
Position Find(Elementype x, BinTree BST){

    if (!BST)

        return NULL;

    BinTree itr = BST;

    while (x != itr->data && itr != NULL){

        if (x < itr->data)

            itr = itr->left;

        else

            itr = itr->right;

    }

    return itr;

}
```

查找效率取决于树的高度

### 查找最大和最小元素

最大元素一定在树的最右分支的端结点上，最小元素一定是在树的最左分支的端结点上

```
Position FindMin(BinTree BST){

    if (!BST)

        return NULL;

    BinTree itr = BST;

    while (itr->left)

        itr = itr->left;

    return itr;

}

Position FindMax(BinTree BST){

    if (!BST)

        return NULL;

    BinTree itr = BST;

    while (itr->right)

        itr = itr->right;

    return itr;

}
```

时间复杂度取决于树的高度

# 二叉搜索树的插入

二叉搜索树的插入与线性结构的插入不同，不存在“中间插入”，而是==在树的某个空位置添加新节点==。关键是要找到该元素应该插入的==位置==，可以采用与Find类似的方法

递归写法：
```
BinTree Insert(Elementype x, BinTree BST){

    if (!BST){

        BinTree newnode = (BinTree)malloc(sizeof(Tnode));

        newnode->left = newnode->right = NULL;

        newnode->data = x;

        return newnode;

    }

    BinTree itr = BST;

    if (x < itr->data){

        itr->left = Insert(x, itr->left);

    }else if (x > itr->data){

        itr->right = Insert(x, itr->right);

    }

    return BST;

}
```

非递归写法：
```
BinTree Insert(Elementype x, BinTree BST){

    BinTree newnode = NULL;

    if (!BST){

        newnode = (BinTree)malloc(sizeof(Tnode));

        newnode->left = newnode->right = NULL;

        newnode->data = x;

        return newnode;

    }

    BinTree itr = BST;

    BinTree parent = NULL;

    while (itr){

        parent = itr;

        if (x < itr->data)

            itr = itr->left;

        else if (x > itr->data)

            itr = itr->right;

    }

    if (x = parent->data){

        return BST;

    }else if (x < parent->data){

        parent->left = newnode;

    }else{

        parent->right = newnode;

    }

    return BST;

}
```

# 二叉搜索树的删除

三种情况：
- 删除==叶节点==：直接删除，并修改其父节点指针为NULL
- 删除==带一个子树的结点==：将其父节点指针指向要删除结点的儿子结点再删除该结点
- 删除==带左、右两个子树的结点==：用另一结点==代替==被删除结点：==右子树的最小元素==或者==左子树的最大元素==

非递归写法：
```
BinTree Delete(Elementype x, BinTree BST){

    if (!BST){

        return NULL;

    }

    BinTree itr = BST;

    BinTree parent = NULL;

    while (itr && itr->data != x){

        parent = itr;

        if (x < itr->data)

            itr = itr->left;

        else if (x > itr->data)

            itr = itr->right;

    }

    if (itr){

        if (itr->left && itr->right){

            BinTree tmp = itr->left;

            BinTree tmpparent = itr;

            while (tmp->right){

                tmpparent = tmp;

                tmp = tmp->right;

            }

            itr->data = tmp->data;

            if (tmpparent == itr){

                tmpparent->left = tmp->left;

            }else{

                tmpparent->right = tmp->left;

            }

            free(tmp);

        }else if (itr->left && !itr->right){

            if (parent == NULL){

                BST = itr->left;

            }else if (parent->left == itr){

                parent->left = itr->left;

            }else{

                parent->right = itr->left;

            }

            free(itr);

        }else if (!itr->left && itr->right){

            if (parent == NULL){

                BST = itr->right;

            }else if (parent->left == itr){

                parent->left = itr->right;

            }else{

                parent->right = itr->right;

            }

            free(itr);

        }else{

            if (parent == NULL){

                BST = NULL;

            }else if (parent->left == itr){

                parent->left = NULL;

            }else{

                parent->right = NULL;

            }

            free(itr);

        }

    }else{

        return BST;

    }

    return BST;

}
```
注意需要使用两个前驱节点，同时注意需删除的结点为根结点的情况，避免其父节点错误访问。

递归写法：

```
BinTree Delete2(Elementype x, BinTree BST){

    if (!BST)

        return NULL;

    if (x > BST->data){

        BST->right = Delete2(x, BST->right);

    }else if (x < BST->data){

        BST->left = Delete2(x, BST->left);

    }else{

        if (BST->left && BST->right){

            BinTree node = FindMax(BST->left);

            BST->data = node->data;

            BST->left = Delete2(node->data, BST->left);

        }else{

            BinTree tmp = BST;

            if (!BST->left){

                BST = BST->right;

            }else if (!BST->right){

                BST = BST->left;

            }

            free(tmp);

        }

    }

    return BST;

}
```
