# 什么是堆(heap)

- 优先队列(Priority Queue)：特殊的==”队列“==，取出元素的顺序是按照元素的==优先权（关键字）==大小，而不是元素进入队列的先后顺序。
	若采用数组或链表实现优先队列：
	- 数组：插入时数据总是插入尾部($O(1)$)，删除时查找最大关键字($O(n)$)后删除并移动($O(n)$)。
	- 链表：插入时数据总是插入头部($O(1)$)，删除时查找最大关键字($O(n)$)后删除结点($O(1)$)。
	- 有序数组：插入时找到合适的位置($O(\log n)$)后移动并插入($O(n)$)，删除时删除最后一个元素($O(1)$)。
	- 有序链表：插入时找到合适的位置($O(n)$)，插入元素 ($O(1)$)，删除时删除首元素或者最后元素($O(1)$)。
	若采用二叉树存储：
	- 若使用二叉搜索树，因为需频繁删除最大值或最小值($O(\log n)$)，可能会造成树的不平衡，减少效率。
因而使用==完全二叉树==表示优先队列，任一结点的关键字是其子树所有节点的最大值或最小值，分别成为“最大堆（大顶堆）”或“最小堆（小顶堆）”。从根结点到任意结点路径上结点序列均有有序性。

# 堆的抽象数据类型描述

- 类型名称：==最大堆（MaxHeap）==
- 数据对象集：==完全二叉树==，每个结点的元素值==不小于==其子节点的元素值
- 操作集: 最大堆$\mathrm{H}\in \mathrm{MaxHeap}$,元素$\mathrm{item}\in \mathrm{Elementype}$,主要操作有:
	- `MaxHeap Create(int Maxsize)`:创建一个空的最大堆
	- `Boolean IsFull(MaxHeap H)`:判断最大堆是否已满
	- `MaxHeap Insert(MaxHeap H, Elementype item)`:将元素插入最大堆
	- `Boolean IsEmpty(MaxHeap H)`:判断最大堆是否为空
	- `Elementype DeleteMax(MaxHeap H)`:返回最大堆中最大元素(高优先级)

# 最大堆的操作

堆一般使用完全二叉树进行存储，故而使用==顺序存储即数组==实现。

## 数据结构及创建

```
typedef struct heap{

    Elementype *element; // array to store the elements;

    int size;            // current amount in the heap;

    int capacity;        // maxsize of the heap;

}heap;

typedef struct heap* maxheap;

maxheap Create(int maxsize){

    maxheap H = (maxheap)malloc(sizeof(heap));

    H->element = malloc((maxsize + 1) * sizeof(Elementype));

    H->element[0] = __INT32_MAX__;

    H->size = 0;

    H->capacity = maxsize;

    return H;

}
```

## 插入

插入时需确保有序性
```
maxheap Insert(maxheap H, Elementype item){

    if (IsFull(H)){

        printf("The heap has been full.\n");

        return H;

    }

    int i = ++(H->size);

    while (item > H->element[i / 2]){

        H->element[i] = H->element[i / 2];

        i /= 2;

    }

    H->element[i] = item;

    return H;

}
```

其时间复杂度为$T(N)=O(\log N)$。

## 删除

取出根结点（最大值）元素并删除堆中的该结点，将最后一个结点移至根后找出其较大的孩子后移动确保其有序性。
关键相当于左子树为堆，右子树为堆，修改为一个新的根结点后如何保证新树仍为最大堆。
```
Elementype DeleteMax(maxheap H){

    if (IsEmpty(H)){

        printf("The heap is empty.\n");

        return -1;

    }

    Elementype ret = H->element[1];

    H->element[1] = H->element[(H->size)--];

    int parent = 1, maxchild = 2 * parent;

    Elementype tmp = H->element[1];

    while (2 * parent <= H->size){

        maxchild = 2 * parent;

        if ( (maxchild != H->size) && (H->element[maxchild] < H->element[maxchild + 1])){

            maxchild++;

        }

        if (H->element[maxchild] > tmp){

            H->element[parent] = H->element[maxchild];

            parent = maxchild;

        }else{

            break;

        }

    }

    H->element[parent] = tmp;

    return ret;

}
```

## 建立

最大堆的建立即为将==已经存在的N个元素==按最大堆的要求存放在一个一维数组中。
方法1：通过上述的1插入操作，将N个元素一个个插入初始为空的堆，时间复杂度为$O(N\log N)$。

方法2：
- 先将N个元素按输入顺序存入满足==完全二叉树的结构特性==。
- 后调整各结点位置，满足最大堆的==有序特性==。

从最后一个有子节点的结点开始调整，保证每一个结点左右子树均为最大堆后将整个结构调整为最大堆。（类似删除操作）
