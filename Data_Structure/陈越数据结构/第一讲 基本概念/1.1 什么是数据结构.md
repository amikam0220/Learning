# 数据结构的官方统一定义：无

## 例1：如何在书架上摆放图书

1. 新书怎么插入？
2. 怎么找到某本指定的书？

- 随便放：便于插入；不便于查找。
- 按字母放：不便于插入，需要每一本都向后错位；便于查找（二分查找）。
- 按种类排序后按字母放：相对便于插入；每一个类里便于二分查找。

==解决问题方法的效率跟数据的组织方式有关。==

## 例2：写程序实现PrintN，打印从1到N的全部正整数

- 迭代
~~~
void PrintN(int N)
{
	int i;
	for (i = 1; i <= N; i++){
		printf("%d\n", i);
	}
	return;
}
~~~
- 递归
~~~
void PrintN(int N)
{
	if (N){
		PrintN(N-1);
		printf("%d\n", N);
	}
	return;
}
~~~

## 例3：写程序计算给定多项式在$x$处的值($f(x)=a_{0}+a_{1}x+\cdots+a_{n}x^{n}$)

$f(x)=a_{0}+x(a_{1}+x(\cdots(a_{n-1}+x(a_{n}))\cdots))$

~~~
double f(int n, double a[], double x){
	int i;
	double p = a[n];
	for (i = n; i > 0; i--){
		p = a[i-1] + x * p;
	}
	return p;
}
~~~

# 什么是数据结构

- ==数据对象==在计算机中的组织方式。
	- 逻辑结构：数据==在逻辑上==如何存储（树状、线性等）。
	- 物理存储结构：数据在==计算机内部实际如何存储==（连续、不连续等）。
- 数据对象必定与一系列加在其上的==操作==相关联。
- 完成这些操作所用的方法就是==算法==。

# 抽象数据类型（Abstract Data Type)

- 数据类型
	- 数据对象集（`int cnt` 中 `cnt` 即为数据对象）
	- 数据集合相关联的操作集（`+ - * /` 等与 `int` 相关的操作组成的集合）
	在C语言中，二者相互独立，在Cpp与Java中，提供类来封装数据集与其相关的操作集。
- 抽象：
	描述数据类型的方法不依赖于具体实现。
	与机器无关，与物理结构无关，与编程语言与算法均无关
仅描述==是什么==，不描述==怎么做==。
