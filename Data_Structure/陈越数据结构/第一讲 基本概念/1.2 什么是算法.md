# 算法定义

- 一个有限指令集
- 接受一些输入（有时不需要）
- 产生输出
- 一定在有限步骤之后终止
- 每一条指令必须有充分明确的目标，不能有歧义，且在计算机能处理的范围之内，并且需要抽象描述不依赖任何一个具体语言

## 例1：选择排序算法的伪码描述

~~~
void SelectionSort (int List[], int N){
	/*将N个整数List[0]...List[N-1]进行非递减排序*/
	for ( i = 0; i < N ; i++ ){
		MinPosition = ScanForMin( List, i, N-1 );
		/*从List[i]到List[N-1]中找最小元，并将其位置赋给MinPosition*/
		Swap( List[i], List[MinPosition] );
		/*将未排序部分的最小元换到有序部分的最后位置*/
	} 
}
~~~

# 什么是好的算法？

## 空间复杂度$S(n)$

占用存储单元的长度

如对于[[1.1 什么是数据结构#^0523d5|PrintN的递归调用]]，其空间复杂度为$S(n)=C\cdot n$, 而其迭代实现的复杂度则为常量$C$。

## 时间复杂度$T(n)$

耗费时间的长度

如对于[[1.1 什么是数据结构#^0b858c|给定多项式的求和]]，该算法的时间复杂度仅为$T(n)=C\cdot n$, 而使用$pow$函数实现的求和则为$T(n)=C_{1}n^{2}+C_{2}n$。

## 关注的两种复杂度

- ==最坏情况复杂度==
- 平均复杂度

# 复杂度的渐进表示法

- $T(n)=O(f(n))$，$f(n)$是$T(n)$的某种上界($\exists C>0,n_{0}>0,\forall n>n_{0} \, s.t. \,T(n)\leq C\cdot f(n)$)
- $T(n)=\Omega(f(n))$，$f(n)$是$T(n)$的某种下界($\exists C>0,n_{0}>0,\forall n>n_{0} \, s.t. \,T(n)\geq C\cdot f(n)$)
- $T(n)=\Theta(f(n))$，$f(n)$既是$T(n)$的某种上界又是某种下界($\exists C>0,n_{0}>0,\forall n>n_{0} \, s.t. \,T(n)\leq C\cdot f(n),T(n)\geq C\cdot f(n)$)

## 常见复杂度的大小比较

$C<\log n<n<n\log n<n^{2}<n^{3}<2^{n}<n!$

## 相关注意点

- 若两段算法分别有复杂度$T_{1}(n)=O(f_{1}(n)),T_{2}(n)=O(f_{2}(n))$,则有：
	- $T_{1}(n)+T_{2}(n)=max(O(f_{1}(n)),O(f_{2}(n)))$
	- $T_{1}(n)\times T_{2}(n)=O(f_{1}(n)\times f_{2}(n))$
- 若$T(n)$是关于$n$的$k$阶多项式，那么$T(n)=\Theta(n^{k})$。
- `for`循环的时间复杂度等于循环次数乘以循环体内代码复杂度
- `if-else`结构复杂度取决于`if`的条件判断复杂度和两个分支部分的复杂度，总体复杂度取三者最大。
