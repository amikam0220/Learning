# 最大子列和问题：给定N个整数的序列$\{ A_{1},A_{2},\cdots,A_{N} \}$，求函数$f(i,j)=\mathrm{max}\left\{  0,\sum_{k=i}^{j}A_{k}  \right\}$的最大值

## 算法1

暴力计算，直接计算所有的子列和并找出最大值。
```
int MaxSubseqSum1(int A[], int N){

    int thissum, maxsum = 0;

    int i, j, k = 0;

    for (i = 0; i <= N; i++){

        for (j = i; j <= N; j++){

            thissum = 0;

            for (k = i; k <= j; k++){

                thissum += A[k];

            }

            if (thissum > maxsum){

                maxsum = thissum;

            }

        }

    }

    return maxsum;

}
```
这个算法的复杂度为$O(N^{3})$。

## 算法2

优化后的暴力算法。减少一个循环量，减少最后一个值之前的重复运算。
```
int MaxSubseqSum2(int A[], int N)

{

    int thissum, maxsum = 0;

    int i, j = 0;

    for (i = 0; i <= N; i++)

    {

        thissum = 0;

        for (j = i; j <= N; j++)

        {

            thissum = A[j];

            if (thissum > maxsum)

            {

                maxsum = thissum;

            }

        }

    }

    return maxsum;

}
```
该算法的复杂度为$O(N^{2})$。

## 算法3：分治法

将一个数组的分为两个部分，分别求两边的最大子列和以及跨越边界的最大子列和，返回其中最大值。
~~~
int MaxSubseqSum3(int A[], int N)

{

    int left = 0;

    int right = N - 1;

    int mid = left + (right - left) / 2;

    if (left == right)

    {

        return A[left];

    }

    int leftmax = MaxSubseqSum3(A + left, mid - left + 1);

    int rightmax = MaxSubseqSum3(A + mid + 1, right - mid);

    int midmax = midsummax(A + left, right - left + 1);

    return (leftmax > rightmax) ? ((leftmax > midmax) ? leftmax : midmax) : ((rightmax > midmax) ? rightmax : midmax);

}

int midsummax(int A[], int N)

{

    int left = 0;

    int right = N - 1;

    if (left == right)

    {

        return A[left];

    }

    int mid = (right - left) >> 1 + left;

    int leftsum = 0, rightsum = 0, tmpsum = 0;

    for (int i = mid; i >= left; i--)

    {

        tmpsum += A[i];

        if (tmpsum > leftsum)

        {

            leftsum = tmpsum;

        }

    }

    tmpsum = 0;

    for (int i = mid + 1; i <= right; i++)

    {

        tmpsum += A[i];

        if (tmpsum > rightsum)

        {

            rightsum = tmpsum;

        }

    }

    return leftsum + rightsum;

}
~~~
该算法的复杂度为$O(N\log N)$。
(计算方法：如果将该算法的复杂度记为$T(N)$，则左右两个部分分别为$T(N / 2)$，中间的部分为$cN$。则有递推公式$T(N)=2T(N/2)+cN,T(1)=O(1)$。最后可得到$T(N)=2^{k}O(1)+ckN,其中N / 2^{k}=1$)

## 算法4：动态规划

```
int MaxSubseqSum4(int A[], int N){

    int thissum = 0, maxsum = 0;

    for (int i = 0; i < N; i++){

        thissum += A[i];/*add one by one to thissum*/

        if (thissum < 0){

            thissum = 0;/*if thissum is less than zero, it has no denotion to maxsum and abandons it*/

        }else if (thissum > maxsum){

            maxsum = thissum;/*renew the maxsum*/

        }

    }

    return maxsum;

}
```
该算法的时间复杂度为$T(N)=O(N)$。
"动态"的意思即为每输入一个数据就进行即时处理，在任何一个地方终止输入都能给出当前的解。
